# Security Research Dataset

Place security research documents here in `.txt` or `.md` format.

## Suggested Content

- Academic papers on vulnerability classes
- Security conference proceedings (Black Hat, DEF CON, CCC)
- Threat intelligence reports
- Malware analysis reports
- Reverse engineering write-ups

## Format

Plain text (`.txt`) and Markdown (`.md`) files are indexed automatically.
For PDFs, convert to text first using a tool like `pdftotext`.
